تنظیمات حساب مدیر

نام کاربری و رمز مدیر را اینجا تعیین کن، یا همه‌چیز را به حالت پیش‌فرض برگردان.

رمز شما ذخیره نمی‌شود. فقط هَش برگشت‌ناپذیر آن (PBKDF2-SHA256 با ۲۱۰٬۰۰۰ دور و Salt تصادفی) نگهداری می‌شود — همان روشی که سرورهای واقعی به‌کار می‌برند. حتی با باز کردن حافظه‌ی مرورگر هم رمز قابل خواندن نیست.

مدیر واقعی روی اینترنت (Supabase)

برای انتشار عمومی روی GitHub Pages، حساب محلی کافی نیست — چون بازی سمت کاربر اجرا می‌شود. مدیر واقعی باید از دیتابیس بیاید.

  1. در بازی ثبت‌نام کن تا حسابت ساخته شود.
  2. در Supabase به SQL Editor برو و این را اجرا کن (ایمیل خودت را بگذار):
update public.profiles set is_admin = true
where id = (select id from auth.users where email = 'you@example.com');
  1. در بازی یک بار خارج و دوباره وارد شو — دکمه‌ی «مدیریت» ظاهر می‌شود.

هیچ‌وقت کلید service_role را در فایل‌های بازی نگذار. فقط anonKey مجاز است. جزئیات در docs/SECURITY.md.
