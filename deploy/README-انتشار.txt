تَقّه بزن — پوشهٔ آمادهٔ انتشار
================================

محتویات این پوشه را (هر ۲ فایل) در ریشهٔ ریپازیتوری آپلود کنید.

  index.html   بستهٔ کامل بازی، رمزشده. همه‌چیز داخلش هست.
  .nojekyll    فایل خالی ولی ضروری — حذفش نکنید.

فایل .nojekyll مخفی است. در گیت‌هاب با دکمهٔ Add file → Create new file
نامش را دقیقاً .nojekyll بگذارید و خالی Commit کنید.

سپس: Settings → Pages → Source: Deploy from a branch → main / (root)

چند دقیقه بعد سایت بالا می‌آید. اگر صفحهٔ قدیمی را دیدید یک بار
Ctrl+Shift+R بزنید (نسخهٔ قبلی service worker ثبت کرده بود؛ این فایل
خودش آن را پاک می‌کند ولی یک رفرش کامل لازم است).

چرا فقط ۲ فایل: قبلاً کل ریپو آپلود می‌شد که هم به سقف ۱۰۰ فایلیِ
گیت‌هاب می‌خورد، هم کل سورس خام را کنار فایل رمزشده منتشر می‌کرد.
برای اجرای بازی هیچ‌کدام لازم نیست.
